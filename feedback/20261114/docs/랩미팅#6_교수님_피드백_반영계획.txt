1번. 메타분류기 ablation을 가장 먼저 보강
========================================================================
원문 대응: <피드백2> 1. 방법론적 novelty의 위치가 약함

1-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

현재 v8의 표 7은 메타분류기 자체가 시험 데이터를 얼마나 잘 분류하는지를 보여준다. 교수님이 요청한 것은 메타분류기를 사용해서 최종 학생 성능이 얼마나 좋아졌는지이므로, 이 표만으로는 답이 되지 않는다.

다음처럼 통합 방식과 후보 처리 방식을 나누는 것이 좋겠다.

교사 점수 통합                  단일라벨만 사용       단일라벨＋두 후보 사용
학습하지 않는 고정 방식         비교 조건 A           비교 조건 B
메타분류기                      비교 조건 C           현재 KAMPA

같은 열에서 비교하면 통합 방식의 차이를, 같은 행에서 비교하면 두 후보 활용의 차이를 볼 수 있다. 학생 구조·정답 부분집합·미라벨 풀·학습 조건은 맞추고, 채택된 의사라벨 수와 품질도 함께 제시해야 한다.

다만 현재 고정규칙의 교사 점수 8개는 합이 1인 9클래스 확률분포가 아니다. 여기에 KAMPA의 “두 확률의 합이 0.95 이상”을 그대로 적용하면 공정한 대조가 되지 않는다. 기타 소음 점수를 포함한 고정 통합 방식을 먼저 정의하고, 기존 고정규칙 결과는 별도 기준선으로 유지하는 편이 좋겠다.

코드에는 이미 두 후보를 제외하는 옵션이 있다. 이 옵션은 두 후보 샘플을 버리므로, 성능 차이에는 사용한 학습자료 수의 차이도 포함된다. 두 후보 손실 자체까지 설명하려면, 같은 샘플을 단일 최상위 라벨로 학습시키는 대조를 추가하는 것이 도움이 된다.

우선 정답 200개와 2,000개처럼 저라벨·고라벨 조건에서 확인하면, 적은 정답에서의 이득과 정답 증가를 활용하는 능력을 함께 볼 수 있겠다. 다만 ablation은 구성요소의 효과를 입증하는 것이고, 방법의 새로움은 가까운 선행연구와의 차이를 통해 별도로 설명해야 한다.

1-B. 필요한 실험과 설계
------------------------------------------------------------------------

[주요 비교: 통합 방식 × 후보 처리의 2×2 비교]

편의상 다음 실험 ID를 사용한다. 이 ID는 계획상의 구분이며 기존 결과 파일명이 아니다.

- F-S: 학습하지 않는 고정 통합 + 단일라벨만
- F-T: 같은 고정 통합 + 단일라벨·두 후보
- M-S: 메타분류기 통합 + 단일라벨만
- M-T: 메타분류기 통합 + 단일라벨·두 후보, 즉 현재 KAMPA에 대응

먼저 확정해야 할 설계:
- 고정 통합에서 8개 이진 교사 출력과 기타 소음을 어떻게 9클래스 분포로 표현할 것인지 정의한다.
- 기타 소음 점수, 정규화, 동점 처리, 확률의 의미를 문서화한다.
- 이 단계에 신규 정답으로 학습하는 처리를 넣었다면 “학습하지 않는 고정 방식”이라고 부르지 않는다.
- 기존 fixed-rule의 임계값·격차 기반 판정과 새 2×2 비교용 고정 통합은 다른 조건일 수 있다. 둘을 같은 결과로 취급하지 않는다.
- 기존 고정규칙 기준선과 정답 전용 학생 결과는 연구의 기존 비교 근거로 보존한다.
- 같은 열에서는 선별 규칙·가중치 산식·손실·학습 조건을 공통으로 적용하도록 설계한다.
- 점수 통합 방식이 바뀌어 실제 채택 수가 달라지는 것은 측정할 결과다. 동일한 규칙을 적용했다는 것과 동일한 샘플이 채택됐다는 것은 구분한다.
- 임계값이나 정규화 방식을 시험 결과에 맞춰 유리하게 고르지 않는다. 필요한 설정 선정은 허용된 개발·검증 자료에서 수행하고 그 자원을 기록한다.

첫 평가 범위 제안:
- 신규 정답 N = 200, 2,000.
- 미라벨 풀 M = 2,000.
- 기존과 같은 5개 시드를 사용하되, 모델 사이에 같은 N·시드의 정답 목록과 미라벨 목록을 대응시킨다.
- 교사 체크포인트, 학생 구조, 사전학습 가중치, 입력 처리, 증강, 학습률·스케줄, 최대 학습 예산, 체크포인트 선정 기준을 맞춘다.
- 초기화·데이터 순서의 대응을 가능한 범위에서 고정하고 실제 설정을 보관한다.
- 조기 종료 때문에 실제 학습 스텝이 달라질 수 있으므로 종료 epoch와 선택된 체크포인트도 기록한다.
- 다른 라벨 수로의 확장은 검증하려는 주장에 따라 정한다. 처음부터 전체 조합을 모두 실행해야 한다고 확정한 것은 아니다.

현재 구현에서 확인한 기반:
- model/make_combiner_labels.py는 단일라벨 전용 cmbone CSV를 생성하는 경로를 갖고 있다.
- model/train_mark5.py의 --no_two_candidate는 두 후보 행을 제외하는 기능이다.
- 옵션이 존재한다는 사실은 해당 조건의 학습·평가 결과가 이미 준비됐다는 뜻이 아니다.
- 두 후보 행을 제외하더라도 미라벨 입력 풀과 배치 구성 정책은 대조 조건과 맞추어, 손실 대상의 변경 외에 불필요한 차이가 생기지 않게 한다.

[보조 비교: 두 후보 손실과 샘플 추가 효과 구분]
- 현재 KAMPA가 두 후보로 채택한 동일한 샘플을 사용한다.
- 한 조건에서는 현재의 두 후보 손실을 사용하고, 다른 조건에서는 해당 샘플의 최상위 클래스 하나를 목표로 사용한다.
- 샘플 목록·신뢰도 가중치·나머지 학습 조건은 동일하게 유지한다.
- 이렇게 해야 “두 후보 샘플을 추가로 사용한 효과”와 “같은 샘플에 두 후보 목표를 부여한 효과”를 더 구체적으로 구분할 수 있다.
- 이 비교는 2×2 기본 비교의 대체물이 아니라, 두 후보 손실 자체를 강조하려는 경우의 보조 실험이다.

1-C. 필요한 계산
------------------------------------------------------------------------

최종 학생의 Accuracy, Macro Precision, Macro Recall, Macro F1을 시드별로 계산하고 평균·표준편차를 산출한다.

각 지표에 대해 같은 N·시드끼리 다음 차이를 계산한다.
- 단일라벨 조건에서 통합 효과: M-S - F-S.
- 두 후보 포함 조건에서 통합 효과: M-T - F-T.
- 고정 통합 조건에서 두 후보 활용 효과: F-T - F-S.
- 메타분류기 조건에서 두 후보 활용 효과: M-T - M-S.
- 상호작용의 기술적 요약: (M-T - M-S) - (F-T - F-S).

이 차이를 계산했다고 바로 통계적 유의성이 입증되는 것은 아니다. 주요 차이의 불확실성은 5번 계획과 연결한다.

의사라벨 생성 단계에서는 다음을 계산한다.
- 전체 미라벨 수, 단일라벨 채택 수, 두 후보 채택 수, 제외 수.
- 채택률 = (단일라벨 수 + 두 후보 수) / 전체 미라벨 수.
- 클래스별 채택 수와 신뢰도 분포.
- 단일라벨 일치율 = 정답과 단일라벨이 일치한 수 / 단일라벨 채택 수.
- 두 후보 포함률 = 정답이 후보 집합에 포함된 수 / 두 후보 채택 수.
- 필요하면 동일하게 채택된 샘플 집합에서의 일치율도 보조 분석한다.
- 단일라벨 일치율과 두 후보 포함률은 서로 다른 지표이므로 같은 종류의 “정확도”처럼 섞지 않는다.

가려 둔 미라벨 정답을 품질 분석에 사용한다면 분석 시점과 용도를 기록한다. 기존 개발 과정에서 해당 주석이 임계값 결정에 사용된 사실도 보존한다. 품질 분석 결과를 보고 시험에 유리한 조건을 고른 뒤 “정답을 전혀 쓰지 않았다”고 서술하지 않는다.

1-D. 보관할 결과물과 원고 반영 위치
------------------------------------------------------------------------

- 실험 조건표: 각 행의 통합 방식, 후보 처리, 임계값, 가중치, 손실, N·M·시드.
- 실행별 설정·데이터 목록·교사 체크포인트 식별 정보.
- 실행별 학습 로그, 선택된 체크포인트, 시험클립별 예측, 네 지표.
- 의사라벨 채택 수·품질 표와 차이 계산표.
- 주요 비교의 표 또는 그림.
- 방법 절에는 두 요인의 정의와 대조 조건을 적는다.
- 결과 절에는 최종 학생 성능의 분리 비교를 적는다.
- 서론·결론에는 실제로 지지된 범위의 기여만 반영한다.
- 기존 표 7의 메타분류기 자체 성능은 보조 근거로 활용하되 학생 ablation을 대신했다고 쓰지 않는다.

1-E. 반영 여부 체크리스트
------------------------------------------------------------------------

[ ] 고정 통합의 9클래스 점수와 기타 소음 처리 방식이 명시되었다.
[ ] 기존 fixed-rule과 새 factorized 조건의 차이가 구분되었다.
[ ] 메타분류기 + 단일라벨 조건을 실제 학생 학습으로 평가했다.
[ ] 고정 통합 + KAMPA 선별절차에 대응하는 조건을 평가했다.
[ ] 통합 방식과 후보 처리 외의 학습 조건을 맞추고 차이를 기록했다.
[ ] 채택 샘플 수와 품질을 함께 제시했다.
[ ] 성능 차이의 부호와 크기, 변동을 그대로 보고했다.
[ ] 두 후보 손실 자체를 주장한다면 동일 샘플 대조가 있거나 해석 범위를 제한했다.
[ ] ablation 결과와 선행연구 대비 novelty 설명을 구분했다.
[ ] 결과가 뒷받침하는 주장만 초록·서론·결론에 반영했다.


========================================================================
2번. 소프트 타깃 비교를 통해 타깃 설계의 이유 확인
========================================================================
원문 대응: <피드백2> 3. 소프트 타깃(distillation) 비교 필요

2-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

이 비교는 “통합 확률 전체를 전달할 수도 있는데, 왜 단일라벨이나 두 후보로 바꾸는가?”에 답한다. KAMPA의 설계 이유와 이전 HSHKD 계열과의 차이를 설명하는 데 직접 연결된다.

같은 메타분류기가 생성한 확률을 사용해 다음을 비교하는 것이 좋겠다.
- 현재 KAMPA의 단일라벨·두 후보 학습.
- 전체 9클래스 확률분포를 이용한 소프트 타깃 학습.

먼저 동일한 채택 샘플과 가중치를 사용하고 목표 표현·손실만 바꾸는 비교를 하면 차이를 해석하기 쉽다. 모든 미라벨 샘플에 소프트 타깃을 주는 방식은 별도 비교로 둘 수 있다. 두 조건을 한 번에 섞으면 선별의 효과인지 타깃 표현의 효과인지 다시 모호해진다.

이 실험을 현재 조건에 맞춘 distillation 기준선으로 설명하되, 이전 HSHKD 모델을 그대로 재현한 것처럼 부르면 안 된다. 결과가 비슷하거나 소프트 타깃이 더 좋아도, 그 결과에 맞춰 두 후보 방식의 주장 강도를 정하면 된다.

2-B. 필요한 실험과 설계
------------------------------------------------------------------------

[주요 비교: 같은 입력·같은 통합 결과·같은 채택 샘플에서 타깃만 변경]

- KAMPA-target: 현재의 단일라벨 또는 두 후보 집합을 사용하는 손실.
- Soft-selected: 같은 샘플에 대해 메타분류기의 전체 9클래스 확률을 목표로 사용하는 손실.

공통으로 유지할 것:
- 같은 교사, 같은 메타분류기, 같은 정답 부분집합과 미라벨 풀.
- 같은 채택 샘플 목록과 샘플별 가중치.
- 같은 학생 구조와 초기화 조건, 증강, 배치 정책, 최적화·종료·체크포인트 선정 기준.
- 지도학습 손실과 미라벨 손실의 결합 방식.
- 기본 대조에서는 현재의 손실 가중치 λ를 공통 적용하고, 별도 조정 시 검증 자원과 탐색 예산을 맞춘다.

첫 평가 범위는 1번과 같은 N = 200·2,000, M = 2,000, 시드 5개를 후보로 한다. 최종 실행 범위는 비용과 검증할 주장에 따라 확정한다.

소프트 목표의 기본 설계 제안:
- 우선 온도 T = 1에서 메타분류기의 원래 확률 q를 사용한다.
- 샘플 i의 소프트 교차엔트로피는 -Σ_c q_i(c) log s_i(c)로 정의할 수 있다.
- 샘플 가중치와 배치 내 정규화 방식은 KAMPA 대조 조건과 일치시킨다.
- 온도 조정 등을 추가한다면 그 정의와 손실 스케일을 기록하고, 시험 결과로 선택하지 않는다.
- 기본 결과가 불리하다는 이유로 소프트 기준선에만 불리한 설정을 유지하거나 탐색 기회를 다르게 주지 않는다.

[선택적 확장: 모든 미라벨 샘플에 소프트 타깃]
- Soft-all: 선별되지 않은 샘플까지 포함한 전체 미라벨 풀에 소프트 타깃을 준다.
- 이 조건은 선별 유무와 학습 샘플 수도 함께 달라지는 실용적 기준선이다.
- 가중치를 균일하게 할지, 미리 정한 신뢰도 규칙을 적용할지 먼저 정의한다.
- Soft-selected와 Soft-all을 구분해서 보고하며, Soft-all과의 차이를 타깃 표현 하나의 효과라고 해석하지 않는다.

구현 전 확인할 점:
- 현재 단일라벨·두 후보 CSV의 최상위 라벨과 신뢰도만으로 전체 9클래스 분포를 복원할 수 있다고 가정하지 않는다.
- 저장된 교사 점수와 해당 실행의 메타분류기 계수·절편·클래스 순서를 확인해 전체 분포를 재현하거나 저장해야 한다.
- 확률의 합, 클래스 순서, 클립 ID, 정답 부분집합의 일치 여부를 검증한다.
- 이전 HSHKD의 전체 모델·데이터·손실 구성을 재현한 실험이 아니라면 “HSHKD 재현 결과”로 명명하지 않는다.

2-C. 필요한 계산
------------------------------------------------------------------------

- 실행별 네 성능지표와 평균·표준편차.
- 동일 N·시드에서 KAMPA-target - Soft-selected의 지표 차이.
- Soft-all을 수행한 경우 그 결과와 채택 샘플 수·가중치 차이.
- 주요 성능 차이의 신뢰구간은 5번 절차에 연결한다.
- 해석에 필요하면 같은 단일라벨 샘플군·두 후보 샘플군에 대한 목표 확률의 분포와 오류 양상을 확인한다.
- 수치가 실제로 차이가 없는지, 변동이 커 결론을 내리기 어려운지, 한 방식이 유리한 조건이 있는지를 구분한다.

2-D. 보관할 결과물과 원고 반영 위치
------------------------------------------------------------------------

- 소프트 타깃 정의, 온도, 손실식, λ, 가중치·정규화 방식.
- 클립별 전체 목표 확률 또는 재현에 필요한 고정된 입력·메타분류기 정보.
- 동일 채택 샘플·가중치 검증 기록.
- 실행별 예측·성능표와 비교 차이.
- 결과 절의 타깃 방식 비교 표 또는 그림.
- 방법·관련연구에서 기존 HSHKD와 현재 소프트 기준선의 관계 설명.
- 비교가 완료되면 “소프트 타깃을 비교하지 않았다”는 기존 한계 문장은 실제 결과 설명으로 교체한다.

2-E. 반영 여부 체크리스트
------------------------------------------------------------------------

[ ] 전체 9클래스 확률이 올바른 실행·클립·클래스 순서로 준비되었다.
[ ] 동일 샘플·동일 가중치의 소프트 대조를 수행했다.
[ ] 목표 표현·손실 외에 달라진 조건을 기록했다.
[ ] 온도·λ·설정 선정 자원과 방식이 명시되었다.
[ ] 전체 미라벨 소프트 학습을 했다면 별도 조건으로 구분했다.
[ ] 이전 HSHKD 전체 모델 재현 여부를 정확히 표현했다.
[ ] 유리하거나 불리한 결과를 모두 보존하고 설계 주장에 반영했다.
[ ] 원고의 “미비교” 문장이 실제 실험 상태와 일치하도록 갱신되었다.


========================================================================
3번. 교사 학습자료를 합친 지도학습 oracle의 데이터 정의
========================================================================
원문 대응: <피드백2> 2. 지도학습 상한선(oracle) 기준선 필요

3-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

교수님이 제안한 비교는 의미가 있다. “교사의 지식을 전달하는 대신, 교사를 학습시킨 정답 데이터를 학생에게 직접 주면 어떠한가?”를 확인할 수 있기 때문이다.

다만 교사 데이터의 음성 라벨은 이진이다. 예를 들어 ‘개 짖음 아님’인 클립이 말소리인지 공사 소리인지 기타 소음인지는 그 라벨만으로 알 수 없다. 이진 음성 샘플을 모두 ‘기타 소음’으로 합치면 잘못된 기준선이 된다.

따라서 교사 학습자료 중 9클래스로 정확하게 대응되는 클립을 확인하고, 중복과 검증·시험 녹음의 겹침을 제거한 뒤 합쳐야 한다. 나머지는 원본 주석 확인이나 재주석이 필요한지 판단해야 한다.

이 결과는 추가 정답 녹음까지 이용할 수 있는 조건의 지도학습 참조선으로 보여주는 것이 적절하다. 더 많은 데이터를 쓴다고 반드시 성능이 높아지는 것은 아니므로, 수학적으로 보장된 상한선처럼 표현하지는 않겠다.

참고로 기존 코드의 ceiling은 미라벨 2,000개의 가려 둔 정답을 복원하는 실험이다. 교수님이 요청한 교사 학습자료 통합 실험과는 다르다.

3-B. 필요한 데이터 점검과 실험
------------------------------------------------------------------------

[먼저 필요한 데이터 점검]

교사 학습자료를 다음과 같이 분류한다.
- 교사의 양성 학습 클립 중 현재 9클래스에 명확히 대응되는 자료.
- 이진 음성 클립이지만 원본 주석으로 9클래스 라벨을 확정할 수 있는 자료.
- 여러 교사에서 중복 사용된 자료.
- 주석이 불충분하거나 여러 목표 클래스와 충돌해 바로 사용할 수 없는 자료.
- 학생 검증·시험 자료와 원녹음·세션이 겹치는 자료.

교사마다 양성/음성 라벨이 존재한다는 이유만으로 모든 자료가 9클래스 정답을 갖춘 것으로 계산하지 않는다. 한 교사의 음성 클립이 다른 교사의 양성 클립과 동일할 수 있으므로, 교사별 목록을 단순 합산하지 않고 동일 클립·원녹음 관계를 확인한다.

필요하면 주석 확인·재주석이 필요한 수와 이유를 목록으로 만든다. 실제 재주석이 필요한 경우 그 작업량과 자원을 별도로 기록한다.

[주요 지도학습 참조선]

- 사용 가능한 교사 학습 클립 중 9클래스 라벨이 확정된 집합을 T_9라고 정의한다.
- 기존 신규 정답 집합 L_N과 T_9를 중복 제거 후 합친다.
- KAMPA 학생과 같은 구조·사전학습 출발점의 모델을 해당 정답으로 지도학습한다.
- 같은 학생 구조를 사용해야 추가 정답 정보의 효과와 모델 구조 차이가 불필요하게 섞이지 않는다.
- 검증·시험 집합은 비교 대상과 공통으로 사용한다.
- 평가용 자료가 합쳐지지 않도록 클립 ID뿐 아니라 원녹음·세션 단위도 확인한다.
- 교사 검증·시험 자료를 교사 학습자료로 임의 확대하지 않는다.
- 클래스 불균형이 커지면 실제 클래스별 수와 사용한 샘플링·가중치 정책을 기록한다.
- 학습 예산과 검증 기반 선택 기준을 명시하고, 자료가 많아진 모델에 불합리하게 짧은 학습을 강제하지 않는다.

자원 조건의 구분:
- KAMPA의 기존 평가: 이미 학습된 교사를 재사용하고 신규 정답 N개를 사용.
- 새 지도학습 참조선: 신규 정답 N개와 추가로 접근 가능한 교사 학습 녹음·9클래스 정답을 사용.
- 두 조건의 이용 가능 정보가 다르므로, 같은 신규 정답 예산의 동등한 경쟁 조건이라고 설명하지 않는다.
- 교수님 요청의 취지는 더 많은 정답을 직접 이용하는 참조선을 통해 교사 지식 재사용의 위치를 판단하는 것으로 반영한다.

[혼동하지 않을 선택적 별도 실험]
- L_N + 미라벨 풀의 복원된 정답을 사용하는 완전지도 비교는 별도 실험이다.
- model/make_ceiling_labels.py의 기존 기능은 이 종류에 해당한다.
- 이 실험을 수행하더라도 “교사 학습자료 통합 oracle을 완료했다”고 표시하지 않는다.

3-C. 필요한 계산
------------------------------------------------------------------------

- 교사별 원본 클립 수와 합집합의 고유 클립 수.
- 9클래스 확정 가능 수, 미확정 수, 충돌 수.
- 중복 제거 전후 수와 클래스별 분포.
- L_N과 T_9의 중복 수.
- 검증·시험 원녹음·세션과의 겹침 및 제외 수.
- 최종 지도학습 정답 수 |L_N ∪ T_9|.
- 추가로 사람이 확인·재주석한 라벨 수가 있다면 그 수.
- 각 N·시드의 네 성능지표와 변동.
- 지도학습 참조선과 KAMPA의 성능 차이.

“원래 존재하던 교사 주석”, “새로 확보한 학생 정답”, “추가로 재주석한 정답”을 구분한다. 단순히 성능이 높거나 낮다는 결과만으로 총 라벨링 비용의 우열을 계산하지 않는다.

3-D. 보관할 결과물과 원고 반영 위치
------------------------------------------------------------------------

- 교사 자료의 9클래스 매핑·중복·제외 장부.
- 최종 학습·검증·시험 목록과 분할 검사 결과.
- 클래스별 수와 자원 조건 표.
- 실행별 로그·예측·성능 결과.
- 실험 절의 “추가 교사 학습자료를 사용할 수 있는 지도학습 참조선” 정의.
- 결과 절의 성능 비교와 그 조건에 맞는 해석.
- 기존 한계의 “이 기준선이 필요하다”는 문장을 실제 수행 결과로 갱신하거나, 자료 부족 시 미해결로 유지한다.

3-E. 반영 여부 체크리스트
------------------------------------------------------------------------

[ ] 이진 음성 라벨을 기타 소음으로 일괄 변환하지 않았다.
[ ] 사용한 교사 자료의 9클래스 라벨 근거가 있다.
[ ] 중복과 검증·시험 녹음의 겹침을 확인했다.
[ ] 최종 학습 수와 클래스 분포를 산출했다.
[ ] 같은 학생 구조로 지도학습 참조선을 평가했다.
[ ] 추가로 이용한 정답·녹음 자원을 원고에 표시했다.
[ ] 이 참조선을 수학적으로 보장된 상한으로 단정하지 않았다.
[ ] 기존 미라벨 정답 복원 ceiling과 구분했다.
[ ] 자료가 부족해 일부만 가능했다면 범위와 미해결 부분을 명시했다.


========================================================================
4번. 분할을 바꾼 평가로 일반화를 보강하고 한계 문장을 정리
========================================================================
원문 대응: <피드백2> 4. 하나의 검증·시험 분할, 일반화와 한계 표현

4-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

새로운 주거공간·녹음기기 데이터를 확보하는 것이 가장 직접적인 보강이지만, 작업 규모가 크다. 우선 현재 자료에서 원녹음·세션 단위로 분리한 복수의 분할을 만들고, KAMPA와 핵심 기준선의 저라벨 성능 차이가 유지되는지 확인하는 것이 현실적이다.

이때 클립만 무작위로 다시 섞으면 안 된다. 교사의 학습이나 체크포인트 선정에 사용된 녹음이 새 시험셋에 들어가는지도 확인해야 한다. 또한 이러한 cross-split 결과는 분할에 대한 안정성을 보여주며, 새로운 집이나 기기에 대한 검증과는 구별해야 한다.

교수님의 “한계를 너무 주장하지 않았으면 좋겠다”는 말씀에도 공감한다. 현재 v8은 초록·실험·한계·결론에 비슷한 조건 설명이 반복된다. 다음처럼 배치하는 것이 좋겠다.

- 방법·실험: 실제 평가 조건과 라벨 예산의 정의를 정확히 설명.
- 결과·논의: 확인된 효과와 그 의미를 중심으로 서술.
- 논의 마지막: 해석에 중요한 미해결 범위만 짧게 정리.

추가 실험으로 해결한 항목은 한계 목록에서 빼고 결과로 옮기면 된다. 이렇게 하면 중요한 조건을 보존하면서도 논문이 계속 자기 약점을 나열하는 인상을 줄일 수 있다.

4-B. 필요한 실험과 설계
------------------------------------------------------------------------

[우선 제안: 녹음·세션 단위의 복수 분할 평가]

- 클립 ID, 원녹음 ID, 세션 ID, 가능하면 주거공간·기기 ID를 확인한다.
- 같은 원녹음에서 잘라낸 클립이 학습·검증·시험으로 흩어지지 않게 한다.
- 각 분할에서 9클래스가 평가 가능한지와 출처별 구성을 확인한다.
- 복수 분할의 수는 자료의 독립 그룹 수와 비용을 보고 확정한다. 예를 들어 서로 다른 3개 분할을 후보로 검토할 수 있으나, 세 분할만으로 충분한 일반화가 자동 입증되는 것은 아니다.
- 우선 KAMPA와 EfficientAT 같은 핵심 비교모델을 대상으로 한다.
- 저라벨 효과를 확인하려면 N = 200을 포함한다. 라벨 수에 따른 관계까지 주장하려면 N = 2,000 등 추가 예산 조건도 함께 평가한다.
- 같은 분할·N·시드에서는 두 모델에 동일한 신규 정답 목록과 공통 시험셋을 사용한다.
- 메타분류기는 각 분할의 학습 정답으로 다시 학습한다. 원래 분할의 메타분류기를 새 시험셋에 그대로 재사용해 학습 정보가 섞이지 않게 한다.
- 데이터 의존 전처리·설정 선정도 각 분할의 허용된 학습·검증 자료 안에서 수행한다.

특히 확인할 교사·개발 정보:
- 교사 학습에 사용된 녹음.
- 교사 체크포인트 선정에 사용된 검증 녹음.
- 의사라벨 임계값 개발에 주석을 참고했던 녹음.
- 새로운 시험셋과 위 자료의 관계.

새 분할에서 겹침이 생기면 제외 가능한지, 교사·설정 선정을 다시 해야 하는지 먼저 판단한다. 기존 임계값과 교사를 고정해 재사용할 수 있다는 가정을 자동으로 두지 않는다.

이미 연구 개발에 사용된 자료를 재분할하는 평가는 회고적 재분할 평가라는 성격도 기록한다. 이를 완전히 새로운 외부 데이터에서의 독립 검증으로 서술하지 않는다.

[더 강한 확장: 새로운 주거공간 또는 기기 평가]

- 메타데이터와 자료가 충분하면 특정 주거공간·기기를 학습에서 제외해 평가하는 조건을 고려한다.
- 실제로 새로 확보한 공간·기기 자료가 있다면 클래스 정의·녹음 조건·주석 방식을 맞춰 평가한다.
- 공간이나 기기만 제외했더니 일부 클래스가 사라지는지 확인한다.
- 전체 데이터 출처를 빼는 실험은 출처와 클래스가 얽혀 있을 수 있으므로, 곧바로 동일한 9클래스 일반화 평가라고 간주하지 않는다.
- 새 자료 수집은 현재 계획 저장 작업에 포함되지 않으며, 필요량과 가능성을 따로 판단한다.

4-C. 필요한 계산과 문장 정리
------------------------------------------------------------------------

실험 계산:
- 분할별 학습·검증·시험의 고유 원녹음·세션 수와 클래스별 수.
- 분할 사이 및 교사·개발 자료와의 겹침 검사.
- 분할·N·시드별 네 성능지표.
- 같은 분할·N·시드에서 KAMPA와 핵심 기준선의 성능 차이.
- 분할별 평균 차이와 시드 변동, 분할 간 차이의 범위.
- 여러 라벨 예산을 평가했다면 예산별 성능 곡선과 차이.
- 같은 녹음이 여러 분할 평가에 재등장한 경우 이를 독립된 새 표본으로 중복 계산하지 않는다.

원고 정리:
- 기존 한계 문장을 항목별로 추출한다.
- “실험으로 해결됨 / 부분 해결 / 미해결 / 다른 절에서 충분히 정의됨”으로 구분한다.
- 해결된 항목은 결과 설명으로 바꾸고, 반복 조건은 방법·실험 절의 명확한 정의로 통합한다.
- 교사 사용 조건, 검증 라벨, 임계값 개발 주석 등 해석에 필요한 사실 자체를 삭제하지 않는다.
- 초록·결론에서 같은 조건을 반복해 핵심 결과가 묻히지 않도록 문장을 정리한다.
- 근거가 확보되지 않은 외부 환경 일반화는 입증된 사실로 확대하지 않는다.

4-D. 보관할 결과물과 원고 반영 위치
------------------------------------------------------------------------

- 분할 목록, 그룹 정의, 분할 생성 규칙과 난수 설정.
- 교사·개발·학생 분할 관계 검사표.
- 분할별 실행·예측·성능표.
- 각 분할에서 실제 수행한 메타분류기 학습과 설정 선정 기록.
- cross-split 결과 표 또는 그림.
- 기존 한계 문장의 이동·축약·해결 근거를 연결한 반영표.
- 방법 절의 평가 설계, 결과 절의 안정성 분석, 논의의 짧고 구체적인 미해결 범위.

4-E. 반영 여부 체크리스트
------------------------------------------------------------------------

[ ] 동일 시험셋의 시드 반복을 cross-split이라고 부르지 않았다.
[ ] 원녹음·세션 단위 분리를 적용했다.
[ ] 교사 학습·체크포인트 선정·임계값 개발 자료와의 관계를 검사했다.
[ ] 분할마다 필요한 학습·선정 절차를 올바른 데이터 범위에서 수행했다.
[ ] 핵심 모델을 동일한 분할·라벨 조건에서 비교했다.
[ ] 분할 안정성과 새로운 공간·기기 일반화를 구분했다.
[ ] 해결된 한계를 실제 결과 설명으로 갱신했다.
[ ] 반복적인 방어 문장은 줄였지만 필요한 평가 조건은 보존했다.
[ ] 아직 검증하지 않은 일반화 범위를 성과로 확대하지 않았다.


========================================================================
5번. 주요 성능 차이의 신뢰구간과 대응 분석
========================================================================
원문 대응: <피드백2> 5. paired test 또는 신뢰구간 부족

5-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

현재 평균±표준편차는 실행 간 변동을 보여주지만, KAMPA와 EfficientAT의 성능 차이에 대한 신뢰구간은 아니다.

우선 동일한 정답 부분집합과 시험클립에서 얻은 대응 예측으로, 주요 비교의 성능 차이와 95% 신뢰구간을 제시하는 방향을 추천한다. 필요하면 paired test를 병기하면 된다. 예측 파일이 남아 있다면 이 부분은 재학습 없이 보강할 가능성이 있다.

중요한 것은 시험클립 430개를 5회 평가했다고 독립 표본 2,150개로 취급하지 않는 것이다. 시드와 원녹음의 반복 구조를 고려해 계산해야 한다. 비교와 지표를 미리 정하고, 유리한 p값만 고르는 방식은 피하는 게 좋겠다.

5-B. 먼저 확인할 자료
------------------------------------------------------------------------

- 모델별·N별·시드별 시험클립 ID와 정답.
- 예측 클래스, 가능한 경우 클래스별 예측 확률.
- 같은 N·시드에서 사용한 정답 학습 부분집합.
- 시험클립의 원녹음·세션 ID.
- 선택된 체크포인트와 해당 예측의 대응.
- 최종 판정 규칙이 모든 모델에서 보정 없는 argmax인지.

지표 평균만 저장되어 있으면 클립 단위 대응 분석을 곧바로 수행할 수 없다. 원시 예측이 없는 경우 체크포인트를 이용한 재평가로 복구 가능한지 판단하고, 재학습이 필요한 상황과 구분한다.

같은 시드 번호를 썼다는 사실만으로 모든 조건이 대응된 것은 아니다. 실제 학습 목록과 시험 ID를 대조한다.

5-C. 필요한 계산
------------------------------------------------------------------------

[기본 계산]
- 저장된 원시 예측으로 네 지표를 다시 계산하여 현재 원고와 대조한다.
- 같은 N·시드에서 모델 A와 모델 B의 지표 차이 Δ를 계산한다.
- 시드별 Δ와 평균 차이를 제시한다.
- 개선 폭은 반올림된 표의 값을 다시 빼지 않고 원래 계산값에서 구한 뒤 최종 표시 단계에서 반올림한다.
- Accuracy와 Macro F1 등의 단위가 비율인지 %인지 확인하고, 차이를 %p로 표현할 경우 변환을 일관되게 적용한다.

[우선 제안: 대응된 성능 차이의 95% 신뢰구간]

먼저 신뢰구간이 어떤 불확실성을 표현할지 정한다.
1) 현재 학습된 모델들을 고정했을 때 시험 녹음 표본의 변동.
2) 같은 분할에서 학습 부분집합·시드가 달라지는 변동.
3) 분할 자체가 달라지는 변동.

한 계산이 이 세 가지를 모두 자동으로 반영한다고 쓰지 않는다.

현재 예측으로 가능한 우선 분석의 예:
- 시험 원녹음·세션 단위로 대응 재표집하는 bootstrap을 검토한다.
- 매 재표집에서 두 모델에 같은 시험 그룹을 적용한다.
- 각 실행의 지표를 재계산하고, 사전에 정한 방식으로 실행 간 평균 차이를 집계한다.
- 기존 5개 학습 실행을 고정해 계산했다면 “현재 실행들에 조건부인 시험표본 불확실성”임을 명시한다.
- 재표집 반복 수, 난수 시드, 그룹 단위, 95% 구간 산출 방식을 기록한다.
- 예를 들어 10,000회 재표집을 후보로 둘 수 있으나, 실제 반복 수와 구간 안정성은 수행 때 확인한다.
- 학습 변동까지 함께 반영하려면 시드와 녹음의 교차 반복 구조에 맞는 별도 설계를 정한다. 단순히 모든 예측 행을 독립으로 재표집하지 않는다.
- cross-split 결과까지 합칠 경우 분할 사이에 재사용된 녹음을 고려한다. 여러 분할을 했다는 이유만으로 결과 행 전체가 독립이 되는 것은 아니다.

[paired test를 추가할 경우]
- 무엇을 대응 단위로 검정할 것인지 먼저 정한다.
- 지표와 표본 구조에 맞는 검정을 선택하고 가정을 기록한다.
- Accuracy의 클립별 정오와 Macro F1은 같은 통계량이 아니므로 같은 검정을 기계적으로 적용하지 않는다.
- 시드 5쌍만 이용하는 분석은 표본 수가 작다는 점을 고려한다.
- 여러 모델·라벨 수·지표를 검정하면 주 비교와 보조 비교를 구분하고 다중 비교 처리 여부를 명시한다.
- 효과 크기와 신뢰구간을 중심으로 해석하고 p값 하나로 결론을 대신하지 않는다.

주요 비교 후보:
- KAMPA 대 EfficientAT의 저라벨 조건.
- 1번에서 메타분류기의 효과를 주장하는 핵심 차이.
- 2번의 KAMPA 타깃 대 소프트 타깃.

네 성능지표의 보고 원칙은 유지한다. 어느 비교·지표를 주 분석으로 삼을지는 결과를 본 뒤 유리한 것만 고르지 않고 분석 전에 기록한다.

5-D. 보관할 결과물과 원고 반영 위치
------------------------------------------------------------------------

- 예측·정답·원녹음 ID를 대응시킨 입력표.
- 지표 재계산 및 기존 결과 대조표.
- 시드별 차이와 신뢰구간 결과표.
- 재표집·검정 코드, 입력 해시, 난수 설정, 반복 수.
- 분석 대상·비교·지표·가정·다중 비교 처리에 대한 설명.
- 방법 절의 통계 분석 설명.
- 주요 결과 표·그림의 성능 차이와 구간.
- 결과 해석과 초록·결론에서의 표현 일치.

5-E. 반영 여부 체크리스트
------------------------------------------------------------------------

[ ] 평균±표준편차와 성능 차이의 신뢰구간을 구분했다.

7-A. 대화에서 설명한 반영 방향
------------------------------------------------------------------------

제목은 교수님이 제시한 “KAMPA: Knowledge Amalgamation with Meta-classifier-guided Pseudo-label Assignment”로 반영하면 된다. 제목에서 음향 분류 대상이 빠지는 만큼, 초록 첫 부분과 키워드에서 주거 소음 분류라는 대상을 명확하게 드러내면 좋겠다.

참고문헌은 BBC 몇 항목을 삭제하는 정도로 끝나기 어렵다. 기존 수집 문헌부터 다시 검토해 서론의 음향 응용 근거와 최근 연구를 보강하면서, 최근 5년 Major 저널 비율과 Major 컨퍼런스 조건을 맞추는 것이 좋겠다. 이 비율은 교수님의 프로젝트 기준으로 적용하고, 저널 자체의 의무 규정이라고 쓰지는 않겠다.

BBC 항목은 실제로 음원 출처이므로, 삭제하더라도 사용한 데이터의 출처 기록은 남겨야 한다. 정식 데이터 논문으로 대체할 수 있는지, 공식 출처 표시는 어떤 형태로 유지할지 따로 정해야 한다. 이전 CSA 논문도 선행 연구와의 관계를 설명하는 항목이므로 단순히 개수를 맞추기 위한 삭제 대상으로 취급하지 않겠다.

Applied Acoustics는 실제 음향 문제에 대한 적용과 실험적 검증을 강조한다. 따라서 서론은 다음 흐름이 적합하다고 본다.

주거 소음의 음원 분류와 정답 확보 부담
→ 기존 음원별 분류기를 재사용할 기회
→ 의사라벨로 학습자료 확대
→ 신규 정답을 교사 통합에도 활용하는 KAMPA
→ 이를 검증하는 실험

서론부터 일반적인 지식증류 설명을 길게 시작하기보다, 이 음향 문제에서 왜 이 방법이 필요한지가 먼저 보이면 좋겠다. 참고문헌 스타일·초록 길이·분량의 정확한 제한은 공식 투고 안내를 확보한 뒤 확정해야 한다. 이번 검토에서는 안내 페이지 접근이 차단되어 그 세부 규정까지 확인하지 못했다.

7-B. 필요한 작업: 제목과 서론
------------------------------------------------------------------------

제목:
- 영어 제목을 교수님 제시안에 맞춘다.
- 표지·본문·문서 속성 등 제목이 반복되는 위치를 대조한다.
- 모델 풀네임, 대소문자, 하이픈과 약어 사용을 통일한다.
- 초록·키워드에서 연구 대상과 분류 과제를 명확하게 제시한다.

서론:
- 음향 문제의 필요성과 정답 확보 부담을 실제 문헌으로 뒷받침한다.
- 기존 음원별 분류기 재사용이라는 조건과 신규 정답 예산을 명확히 한다.
- 의사라벨 활용의 효과를 먼저 설명한다.
- 신규 정답을 메타분류기 학습에도 활용하는 이유를 그다음에 연결한다.
- 기여별로 어떤 실험이 답하는지 연결한다.
- 서론의 연구 공백이 기존 문헌 검토에서 실제로 도출되는지 확인한다.
- “문헌을 찾지 못함”을 “분야에 연구가 전혀 없음”으로 바꾸지 않는다.
- 방법의 새로움을 알려진 로지스틱 회귀나 stacking 자체의 발명처럼 설명하지 않는다.
- 주거 소음 분류에 대한 결과를 실제 건물의 소음 저감, 현장 배치 성능, 새로운 기기 적응까지 입증한 것처럼 확대하지 않는다.
- 결론은 서론에서 제기한 질문에 실제 결과로 답하도록 쓴다.
- 초록은 본문·결론·추가 실험 결과가 확정된 뒤 마지막에 정리한다.

이 단계는 새 실험 결과를 생성하는 작업이 아니라, 1~5번의 실제 근거와 문헌을 연결하는 집필 작업이다.

추가 기록: 기존 자료로 가능한 계산과 추가 실험 범위 (2026-11-14)
========================================================================

사용자 확인: 1~4번은 추가 실험이 필요한 범위다. 5번은 기존 결과 기반 통계 분석, 6~7번은 문서·문헌 작업이다. 단, 1~4번에도 먼저 계산·준비할 수 있는 부분이 있다.

확인한 자료:
- 교사 점수 4,860개: labeled 2,000 / unlabeled 2,000 / val 430 / test 430.
- 라벨 수·시드별 메타분류기 계수·절편·클래스 순서.
- 최종 학생 실험 40회의 시험 예측: 메타분류기 의사라벨 30회, 고정규칙 5회, 정답 전용 5회.
- 위 40회 모두 동일 시험클립 430개와 정답에 대응함을 확인했다.
- 단일라벨 전용 cmbone 의사라벨 파일도 실험원자료 사본에 있다. 파일 존재는 해당 조건의 학생 학습 완료를 뜻하지 않는다.

1번. 메타분류기 ablation
기존 자료 계산: 단일·두 후보 채택 수, 의사라벨 품질, 고정규칙·메타분류기 출력 비교, 실험용 타깃 생성.
추가 실험: 두 후보를 끈 학생, 고정 통합+KAMPA 선별 학생 등의 새 학습·평가.
판정: 학생 추가 학습 필요. 이번 확인 범위에서 요청한 새 조건에 맞는 최종 학습 결과는 찾지 못했다.

2번. 소프트 타깃 비교
기존 자료 계산: 저장된 교사 점수와 메타분류기 계수로 전체 9클래스 확률을 재현하고 소프트 타깃 준비.
추가 실험: 소프트 타깃으로 학생을 새로 학습해 현재 KAMPA와 비교.
판정: 교사 재학습은 필요하지 않지만 학생 추가 학습은 필요하다. 현재 학생의 예측을 가공해 새 학생의 성능을 대신 만들 수 없다.

3번. 지도학습 oracle
기존 자료 계산: 교사 자료 라벨 매핑, 중복·분할 겹침 점검, 사용 가능한 정답 수·클래스 분포 계산.
추가 실험: 교사 학습자료를 합친 정답 집합으로 지도학습 모델을 새로 학습.
판정: 자료 정리 후 추가 학습 필요. 기존 주석으로 9클래스가 확정되면 새 녹음·새 주석 없이 구성할 수 있고, 불충분한 자료는 추가 확인·재주석이 필요할 수 있다.

4번. cross-split·외부 환경 평가
기존 자료 계산: 원녹음·세션별 분할 설계, 겹침 검사, 기존 결과의 출처별 분석.
추가 실험 A: 기존 자료 cross-split은 새 분할에서 학생·메타분류기를 다시 학습하고 평가. 교사 재사용 가능 여부는 교사·개발 자료와의 겹침에 따라 판단.
추가 실험 B: 별도 공간·기기 데이터가 이미 있다면 기존 학습 모델을 고정한 추론·평가도 가능. 적합한 자료와 정답이 없으면 확보 작업 필요.
판정: 추가 평가실험 필요. cross-split은 추가 학습이 필요하지만 외부 데이터의 고정 모델 평가는 재학습 없이 가능하다. 기존 결과의 출처별 분석을 외부 환경 평가로 대신하지 않는다.

5번. 신뢰구간·paired test
기존 자료 계산: 동일 클립에 대한 대응 예측으로 성능 차이·신뢰구간·적절한 검정 계산.
판정: 원칙적으로 재학습 없이 가능. 원시 예측이 없으면 저장된 체크포인트로 재추론하여 복구할 수 있는지 먼저 확인한다.
현재 확인: KAMPA·고정규칙·정답 전용 예측은 확보됨. 직전 로컬 점검에서는 EfficientAT 원시 예측을 찾지 못했고 Drive의 실행·평가 로그만 확인했으므로, 해당 비교의 원시 예측 확보를 이어서 점검한다. 파일을 못 찾았다는 이유로 재학습 필요라고 단정하지 않는다.

6번. 본문·부록 분리
필요 작업: 내용 배분, 핵심 정보의 본문 이동, 참조·수치·분량 검사, 문서 생성.
판정: 이 항목 자체를 위한 추가 실험은 없다. 다만 1~5번의 결과가 나온 뒤 최종 내용을 확정한다.

7번. 제목·참고문헌·서론 정리
필요 작업: 제목 수정, 문헌 검토·비율 계산, 서론 재구성, 저널 형식 점검.
판정: 이 항목 자체를 위한 추가 실험은 없다. Major 인정 기준 등 미정인 판단은 계산만으로 확정할 수 없다. 서론의 기여·결론·초록은 실제 추가 실험 결과에 맞춰 확정한다.

권장 순서:
5번의 자료 확보·통계 분석 준비와 1~2번 타깃 준비, 3~4번 데이터 점검을 먼저 수행한 뒤 부족한 근거에 해당하는 학생 학습만 추가한다.
