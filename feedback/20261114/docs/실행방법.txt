KAMPA 교수님 피드백 추가실험 노트북 사용법

1. 01_피드백1~3_추가실험.ipynb를 Google Colab에서 업로드한다.
2. CPU로도 실행할 수 있다. GPU를 사용할 경우 L4를 우선 사용하고 Blackwell 계열은 제외한다.
3. 위에서부터 셀을 실행한다. Google Drive 연결을 허용한다.
4. 기본 경로는 /content/drive/MyDrive/NewProject/codes/experiments/Mark5.3 이다.
   기존 Mark5.2 음원, Mark4.1~4.8 교사 음원, Mark5.3 메타 계수·점수·사전학습 가중치를 사용한다.
   실행 코드와 출처 메타데이터는 ipynb 안에 들어 있어 ZIP을 별도로 업로드할 필요가 없다.
5. 기본 N=200으로 1~3번 45회, 4번 30회다. 총 75회이므로 여러 런타임에 걸쳐 실행할 수 있다.
   N=2,000도 필요하면 각 노트북의 LABEL_BUDGETS를 [200, 2000]으로 바꾼다. 총 150회가 된다.
   200개 조건으로 실행했다는 사실을 보고서에 표시해야 하며 2,000개 조건의 결론을 대신하지 않는다.
6. 데이터 검사와 선택한 CPU/GPU 환경의 모델 연산 검사 후 '실제 실험 실행' 셀이 학습을 시작한다.
7. 완료·중단 상태는 Drive에 저장한다. 같은 설정으로 다시 실행하면 완료 회차는 건너뛰고
   중단 회차는 마지막으로 저장된 에폭부터 이어간다. CPU/GPU 환경과 패키지가 달라지면 결과 폴더가 자동 분리된다. 코드를 바꾸면 새 결과 폴더를 사용한다.
8. 02_피드백4_출처별_재분할검증.ipynb도 같은 방식으로 실행한다. 순서 의존성은 없다.

Drive 결과 위치:
NewProject/codes/experiments/KAMPA_feedback_20261114_v2/<환경해시>/1_3/
NewProject/codes/experiments/KAMPA_feedback_20261114_v2/<환경해시>/4/

확인할 파일:
- run_plan.csv: 예정 회차
- audit/preflight.json, audit/audio_files.csv: 입력·라벨·분할·음원 버전 검사
- audit/teacher_oracle_audit.csv: 교사 자료의 클래스 복원·중복 제외 근거
- splits/: 4번의 새로운 train/val/test 명단
- runs/<회차>/complete.json: 해당 회차 완료 및 산출물 해시
- runs/<회차>/last.pt, best.pt, history.csv: 학습 재개·최적 체크포인트·학습곡선
- runs/<회차>/train_manifest.csv, pseudo_targets.csv: 실제 학습 자료와 전체 분포/가중치
- runs/<회차>/test_predictions.csv, metrics.json: 클립별 예측·Accuracy·Macro-F1·혼동행렬
- results_all_runs.csv, results_summary.csv: 완료 회차 집계
- ablation_factorial_effects.csv: 1번 2×2 주효과·상호작용
- paired_seed_differences.csv: 같은 seed에서 대조군과의 차이
- oracle_vs_supervised.csv: 3번 추가 교사 정답의 성능 차이

주의할 해석:
기존 논문 결과를 새 대조군 대신 끼워 넣지 않는다. 새 코드로 다시 학습한 대조군끼리 비교한다.
oracle은 추가 정답이 있는 특권적 참고 성능이다. 실제 우열은 실험 결과로 확인해야 한다.
12,477개 파일은 원본 4,694개와 증강 7,783개를 합친 수이며 출처 그룹은 4,089개다.
이를 독립적인 새 정답 12,477개 또는 새 녹음 12,477개로 보고하지 않는다.
4번은 현재 데이터의 출처 그룹 재분할 검증이며 새로운 집/기기 녹음을 대신하지 못한다.
현재 원래 VAL에는 교사 train/val과 출처 그룹 1개가 겹친다는 감사 결과가 있다.
원래 TEST에서는 겹침이 확인되지 않았고, 4번 새 VAL/TEST는 해당 그룹을 제외하도록 구성했다.
노트북 작성·구현 검증을 마쳤으며, 실제 연구용 학습은 사용자가 실행할 단계다.
